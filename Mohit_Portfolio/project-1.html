Jagannath Dham

Jagannath Dham is a full-stack darshan and tourism platform developed using Java, Spring Boot, React, and TiDB Cloud. Project Overview

Jagannath Dham is a full-stack darshan and tourism platform designed to simplify the temple visit and booking experience. It allows devotees to register, log in, book darshan slots, and access digital QR tickets for entry verification.

The platform also provides destination discovery across Odisha, allowing users to explore tourist destinations and access relevant information. It also features a Festivals of Odisha section where logged-in users can view festival information. Administrators can manage and update festival details.

The platform integrates Google Gemini AI to provide AI-powered assistance, adding an intelligent feature to the user experience.

The system includes three dashboards: Devotee, Staff, and Admin. Staff can scan and verify QR tickets, prevent duplicate scans, and monitor gate activity. Admins can manage users, staff, bookings, darshan slots, destinations, festivals, and platform operations.

The backend REST APIs are developed using Java 21 and Spring Boot, with Spring Security and JWT for authentication. The frontend is built using React, while TiDB Cloud provides database hosting. The application demonstrates full-stack development, authentication, database integration, QR-based ticketing, and cloud deployment.

Additional integrations include Razorpay for payment processing, Weather API for weather information, and SendLiberty Email API for email communication.
