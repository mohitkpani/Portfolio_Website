A full-stack Banking Management System built using Java Spring Boot, MySQL, HTML, CSS, and JavaScript, featuring user registration, secure account management, deposits, withdrawals, transaction history, admin and user dashboards, email notifications, and Razorpay Test Payment Integration. Project Overview

The Banking Management System is a full-stack web application developed using Java Spring Boot, MySQL, HTML, CSS, and JavaScript to manage essential banking operations efficiently. The system provides separate user and admin dashboards, allowing users to register, securely access their accounts, create bank accounts, deposit and withdraw money, and view transaction history. The application also includes email notifications and Razorpay Test Payment Integration for demonstrating online payment processing. Spring Data JPA and Maven are used for database interaction and project dependency management.

The application follows a structured architecture with a Spring Boot backend and a responsive frontend to provide a smooth user experience. MySQL is used for reliable storage and management of user, account, and transaction data, while proper validation and secure account access help maintain data integrity. The backend REST APIs were developed and thoroughly tested using Postman to verify different banking operations and API responses. The project also integrates Razorpay Test Payment for demonstrating online payment processing and transaction workflows.
