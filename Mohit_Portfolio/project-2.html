🖨️ Mahesh Print Services (QuickPrint)

QuickPrint is a QR-based document printing platform developed using React, Java, and Spring Boot. It allows customers to upload documents and photos through a QR-linked webpage, while shop administrators can access and print uploaded files from the shop dashboard.

Project Overview

Mahesh Print Services (QuickPrint) is a full-stack web-based printing solution developed for Mahesh Digital Studio. It simplifies document submission by allowing customers to scan a QR code and upload PDF files and photos directly from their mobile devices without visiting the shop's computer.

The application provides separate customer upload and shop administrator interfaces. Customers can upload their documents through a mobile-friendly webpage, while the shop administrator can view uploaded files on the shop computer and print them directly.

The backend is developed using Java and Spring Boot, while the frontend uses React and JavaScript. The application supports document and image uploads, QR-based access, and shop-side printing workflows. Uploaded files are removed after printing to avoid unnecessary file storage.

This project demonstrates full-stack application development, REST API integration, file handling, QR code implementation, and practical problem-solving for a real-world local business.
