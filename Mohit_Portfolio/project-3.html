StayMate – Rental & PG Management Platform

A backend-focused Rental and PG Management Platform developed using Java Spring Boot, providing REST APIs for property management, JWT authentication, property search and filtering, bookings, Razorpay payments, Cloudinary image management, and email notifications.

Project Link

Project Overview

StayMate is a Rental and PG Management Platform developed using Java Spring Boot, designed to simplify property discovery, rental management, bookings, payments, and user management. The platform provides REST APIs for user authentication, property management, property search and filtering, booking management, payment processing, image management, and email notifications. It implements JWT-based authentication, role-based access control, password encryption using BCrypt, and Google OAuth2 login. Property owners and administrators can manage properties, availability, images, and bookings, while Cloudinary is used for property image storage and Razorpay is integrated for payment processing.

The application follows a structured layered architecture consisting of Controller, Service, Repository, and Database layers. MySQL is used for data storage with Spring Data JPA and Hibernate for database interaction and persistence. The platform supports booking creation, room selection, booking amount calculation, booking cancellation, payment verification, and payment status tracking. Email notifications are implemented for welcome messages, booking confirmations, payment confirmations, and cancellations. The backend REST APIs were tested using Postman, while Maven is used for project build and dependency management. Properties also support latitude and longitude information for location-based functionality.
