Project Overview

ResumeCraft is a full-stack smart resume builder designed to simplify the process of creating professional resumes. It provides an interactive interface where users can enter their personal information, educational qualifications, technical skills, projects, and work experience while viewing a live resume preview.

The application allows users to generate and download professional resumes in PDF format. It also includes an email integration feature that enables users to send their generated resumes directly through email.

The frontend is developed using React and JavaScript, while the backend REST APIs are built using Java and Spring Boot. PDF generation is implemented using html2canvas and jsPDF. The application is deployed using Vercel for the frontend and Render for the backend.

This project demonstrates full-stack development, REST API integration, dynamic UI rendering, PDF generation, email communication, and cloud deployment.
